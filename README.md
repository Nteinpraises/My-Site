# Ntein Praises | AI Automation Engineer Portfolio

Personal portfolio of Ntein Praises Ankinimbom, AI Automation Engineer.

Focus: AI agents, workflow automation, business process automation, CRM and lead
automation, APIs and integrations, built on a software engineering foundation.

Live site: https://nteinpraises.vercel.app

## Structure

- `public/index.html`, `public/index.css`, `public/index.js` — the portfolio site
- `public/img/` — logo, profile photo and project screenshots
- `public/resume.pdf` — downloadable resume
- `public/robots.txt`, `public/sitemap.xml` — search engine files
- `src/` — TanStack Start app shell that serves the portfolio

## Development

```sh
npm install
npm run dev
```
